# Milestone Escrow on Arc ⚡

## Overview
A trustless freelance milestone escrow dApp built on the Arc Network. This smart contract allows clients to lock USDC into an agreement and release funds step-by-step as work is delivered.

## Why Arc Network?
Cross-border freelance payments suffer from high platform fees. Traditional crypto escrows confuse non-crypto users with the need to hold volatile gas tokens just to approve a transaction. 

Arc's native USDC gas model solves this. Clients and freelancers don't need to manage a dual-token treasury. Funds are locked and released with predictable, sub-cent network fees paid directly in USDC.

## Smart Contract Details
- **Network:** Arc Mainnet
- **Contract Address:** `0xC5EBb072AD74F45ed716B50F581f34807cb6B67d`
- **Gas Token:** USDC

## Features
- Secure USDC locking
- 3-step milestone releases
- Trustless refund mechanism on deadline expiration
